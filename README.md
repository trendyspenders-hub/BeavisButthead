# Beavis And Butthead by I.R.Evan

Mac AU/VST3 guitar amp plug-in based on Neural Amp Modeler, with animated artwork, a pedal drawer, six captures and three cabinet IRs.

GitHub Actions builds a universal Intel/Apple Silicon test PKG and DMG. Download the installer artifact after a successful build. Test installers are not Developer ID signed or notarized. Pro Tools/AAX is deferred.

On a Mac with full Xcode, run `bash scripts/build-mac.command`. It fetches the pinned engine dependencies and original resources. See docs/START-HERE.md and docs/FINISH-RELEASE.md for testing and release details.
